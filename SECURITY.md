# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability affecting TypeCraft Skills, please report it privately to the project maintainers.

Do not disclose exploitable vulnerabilities publicly before maintainers have had an opportunity to investigate.

## What to Include

Please provide:

- A description of the vulnerability.
- Steps to reproduce the issue.
- Affected files or components.
- Potential impact.
- Any suggested remediation.

## Response Process

Project maintainers will:

1. Review the report.
2. Assess the severity and potential impact.
3. Investigate and work on an appropriate fix.
4. Coordinate disclosure when appropriate.

## Scope

Security reports may include:

- Malicious or unsafe instructions in resource files.
- Unexpected behavior in validation scripts.
- Exposure of credentials or sensitive information.
- Vulnerabilities in project automation or distribution.

## Important

TypeCraft Skills provides design instructions and resources. Security issues in external AI agents, rendering tools, or third-party services should also be reported to their respective maintainers.
