# TypeCraft Skills — Installation Guide

## Overview

TypeCraft Skills is distributed as one Agent Skill.

The skill directory is:

`skills/typecraft-skills/`

## 1. Get the Repository

Clone the repository:

    git clone https://github.com/krupakar5535Kk/typecraft-skills.git

Open the downloaded repository:

    cd typecraft-skills

## 2. Locate the Skill

The installable skill is located at:

`skills/typecraft-skills/`

It contains the main `SKILL.md` file, reference resources, examples, and supporting assets.

## 3. Install in an AI Agent

Installation procedures depend on the AI agent and its supported skill-discovery mechanism.

Use the installation method documented by your target agent. Where supported, install or link the complete `skills/typecraft-skills/` directory into the agent's designated skills location.

Do not assume that every AI agent uses the same directory structure or installation procedure.

## 4. Verify Installation

After installation:

1. Confirm that the agent can discover the `typecraft-skills` skill.
2. Confirm that it can read the main `SKILL.md` file.
3. Ask it to select a typography style or design template.
4. Check that it follows the selection rules and resource instructions.

## 5. Troubleshooting

**Skill not discovered**

Check the installation location and the agent's skill-discovery requirements.

**References not available**

Ensure that the complete skill directory was installed, not only `SKILL.md`.

**Unexpected design selection**

Check whether the request specifies Automatic, Manual, or Mixed selection mode.

## Important

Platform-specific installation instructions must be verified before being presented as officially supported procedures.

See the compatibility guide: compatibility.md.
