# TypeCraft Skills — Usage Guide

## 1. Overview

TypeCraft helps AI agents apply typography styles and design templates to creative projects.

Users can request a style, a template, or a combination of both.

## 2. Basic Request

Describe the intended output, subject, audience, and target medium.

Example:

Create a promotional poster for a technology conference.

## 3. Selecting Resources

### Automatic Mode

Allow the agent to choose suitable typography styles and design templates.

### Manual Mode

Specify the exact style or template to use.

### Mixed Mode

Specify one resource and allow the agent to select the other.

Explicit choices must never be silently overridden.

## 4. Using a Typography Style

A typography style defines the visual personality and treatment of text.

Example:

Create a poster using the Swiss International Typographic Style.

## 5. Using a Design Template

A design template defines the structural arrangement of content.

Example:

Use the Cinematic Title Poster template for a film announcement.

## 6. Combining Resources

A style and template may be combined when appropriate.

Example:

Apply the Art Deco Typographic Style to the Swiss Grid Editorial Poster template.

The selected style should guide typography treatment while the template guides composition.

## 7. Resource Lifecycle

Resource statuses determine how resources should be used:

- Approved: Available for normal production use.
- Review: Evaluation and testing only; disclose its review status.
- Draft: Development and testing only.
- Deprecated: Do not automatically select; use only when explicitly requested and appropriate.

## 8. Domain Adaptation

Adapt the selected resources to the intended output:

- Static Graphics
- Motion Graphics
- Video
- Web and UI
- Editorial

Preserve the core design direction while respecting the technical requirements of the target medium.

## 9. Output Expectations

Explain the selected resources and the design direction.

Provide practical execution instructions appropriate to the available tools.

Identify limitations instead of claiming unsupported capabilities.
