# Contributing to TypeCraft Skills

Thank you for your interest in contributing to TypeCraft Skills.

## Ways to Contribute

- Create new typography styles.
- Create new design templates.
- Improve existing resources.
- Improve documentation.
- Report bugs and inconsistencies.
- Suggest new creative capabilities.

## Before Contributing

1. Read the project README.
2. Review docs/architecture.md.
3. Read docs/authoring-standard.md.
4. Review docs/resource-schema.md.
5. Follow the existing resource structure.

## Resource Contributions

Every new resource must:

- Follow the applicable resource schema.
- Use a unique permanent resource ID.
- Include the required metadata.
- Follow the authoring standard.
- Include practical execution instructions.
- Document limitations and references.
- Declare an appropriate lifecycle status.

Do not reuse IDs assigned to existing resources.

## Pull Requests

1. Create a separate branch for your changes.
2. Make focused, clearly documented changes.
3. Validate modified resources.
4. Explain the purpose of your contribution.
5. Submit a pull request for review.

## Quality Expectations

Contributions should prioritize clarity, originality, usability, accessibility, and consistency.

All contributions are subject to maintainer review before approval.

Thank you for helping improve TypeCraft Skills.
